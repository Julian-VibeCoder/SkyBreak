# SkyBreak

**SkyBreak: Plan your quick airplane getaways**

A tool for planning short trips and weekend getaways by air.

## Features
- ✈️ Flight search & comparison
- 📍 Destination recommendations
- 📅 Flexible date planning
- 💰 Budget optimization

## Quick Start
```bash
git clone https://github.com/Julian-VibeCoder/SkyBreak.git
cd SkyBreak
npm install
npm start
```
